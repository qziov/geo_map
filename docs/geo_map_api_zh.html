class GeoPopupController extends ChangeNotifier

成员

方法
  • void dispose()
  • void registerPopup(String sourceId, GeoPopupBinding binding) Bind a popup to [sourceId] imperatively. Call from a layer's setup and pair it with [unregisterPopup] on teardown so stale bindings never fire.
  • void unregisterPopup(String sourceId) Drop an imperative binding. If it is the one currently shown, the popup closes.

  • List<GeoQueryHit> handleTap(
  LatLng tap, {
  required GeoMapController controller,
  required GeoFeatureRegistry registry,
  double? pointRadiusPx,
  List<GeoQueryHit>? hits,
})
    The single entry point for a map tap. Queries [registry], filters to sources that registered a popup, and opens the highest-priority one. No hit, or a hit on a source without a popup (e.g. an airport that only fires a SnackBar), closes any open popup. Pass [hits] when the host already ran the query (it usually needs the same results for its own business reactions) — this avoids querying twice. Disposed controller (see [isDisposed]) → no-op: the popup it owned no longer exists, and the freshly created replacement will handle the next tap. 取值

splitRingAtSeam函数

List<List<LatLng>> splitRingAtSeam(List<LatLng> ring, double seamLng)

在经线 [seamLng] 处切分 [ring]，返回一个或两个闭合片段。

先展开环，因此 +179°/−179° 的边会被识别为跨越接缝。若环完全位于一侧，则原样返回 [ring]。顶点少于三个的片段被丢弃。

这对应 MapLibre 在切片时于 ±180° 切分 GeoJSON 的行为。渲染器自身只需要 [unwrapLongitudes] 加世界副本；此辅助函数让该行为可测试，并允许调用方显式裁剪。

unwrapLongitudes函数

List<double> unwrapLongitudes(List<double> lons)

顺序展开 [lons]，使每对相邻差值都落在 (-180, 180]。

out[0] == lons[0]；out[i] = out[i-1] + wrapLongitude(lons[i] - lons[i-1])。一条从 +179° “跳”到 −179° 的环会变成 +179° → +181°（2° 步长）而非 −358° 步长，从而可被连续投影。
